### Project overview

My primary personal project is **JARVIS AI Assistant**—an exploration of how to build a capable desktop assistant that goes beyond a conventional chatbot.

The vision is to create an assistant that understands requests, plans its next steps, uses approved tools, and verifies whether an action succeeded.

### Core capabilities

| System                | Objective                                                          |
| --------------------- | ------------------------------------------------------------------ |
| 🧠 AI Brain           | Understand instructions and help plan tasks                        |
| 💾 Persistent Memory  | Preserve useful information across conversations                   |
| 🎙️ Voice Interface   | Support English, Hindi, and Hinglish interaction                   |
| 👁️ Screen Awareness  | Interpret relevant information from the computer screen            |
| ⚙️ Desktop Automation | Execute approved computer operations                               |
| 🔐 Security Layer     | Validate actions and request confirmation for sensitive operations |
| ✅ Verification        | Check results instead of assuming every action succeeded           |
| 🖥️ Mission Interface | Create a futuristic, JARVIS-inspired experience                    |

### Execution philosophy

<div align="center">

`INPUT` → `UNDERSTAND` → `PLAN` → `EXECUTE` → `VERIFY`

</div>

The goal isn't merely to build an assistant that answers questions. It's to explore how an AI system can understand context, use tools responsibly, maintain continuity, and produce verifiable results.

*Current focus: developing and evaluating core capabilities before expanding into more advanced automation.*
