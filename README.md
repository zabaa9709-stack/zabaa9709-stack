### `PROJECT OVERVIEW`

My primary personal project is **JARVIS AI Assistant**—an attempt to build a capable desktop assistant that goes beyond a simple chatbot.

The vision is to create an assistant that can understand a request, reason about the next step, use approved tools, and verify whether an action succeeded.

### Core capabilities I'm exploring

| System                | Objective                                                          |
| --------------------- | ------------------------------------------------------------------ |
| 🧠 AI Brain           | Understand instructions and help plan tasks                        |
| 💾 Persistent Memory  | Preserve useful information across conversations                   |
| 🎙️ Voice Interface   | Support natural interaction in English, Hindi, and Hinglish        |
| 👁️ Screen Awareness  | Interpret relevant information from the computer screen            |
| ⚙️ Desktop Automation | Execute approved computer operations                               |
| 🔐 Security Layer     | Validate actions and request confirmation for sensitive operations |
| ✅ Verification        | Check results instead of assuming every action succeeded           |
| 🖥️ Mission Interface | Create a futuristic, JARVIS-inspired user experience               |
